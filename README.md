## 🇩🇪 Deutsch

Meine persönliche GitHub-Pages-Startseite mit Links zu meinem Portfolio und meinen Lernprojekten.

### Funktionen

- Startseite mit Portfolio-Überblick und Kontaktmöglichkeit.
- Direkte Links zur KI-Lernwerkstatt und zum sokratischen Tutor.

### Technik und Datenschutz

Die statische HTML-Seite wird über GitHub Pages bereitgestellt. Sie benötigt kein Backend, ruft kein KI-Modell auf und enthält keine API-Schlüssel. Die Auswahl des Farbmodus wird lokal im Browser gespeichert.

### Start

Die [Startseite](https://daniilobrant.github.io/) im Browser öffnen oder index.html aus diesem Repository lokal aufrufen. Eine Installation ist nicht erforderlich; die Seite ist keine PWA.
